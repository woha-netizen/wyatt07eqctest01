IAM Demo Application

Welcome to the Cloudflare IAM demonstration website.

This page represents a protected web application. Access should only be granted to authorised users.

Application is running

Log in Create account Open dashboard How it works

  1. Identify

    Create an account, or sign in with your email or username.

  2. Verify

    Your password is checked against a salted hash. Five wrong attempts lock the account for ten minutes.

  3. Authorise

    Your role decides which pages open. Administrators also reach the admin console.
